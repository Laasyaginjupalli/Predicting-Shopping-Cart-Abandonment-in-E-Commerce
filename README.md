## Predicting Shopping Cart Abandonment in E-Commerce

Developed a machine learning project to predict customer shopping cart abandonment using e-commerce behavioural data from Kaggle.

- Cleaned and processed customer activity data using Python.
- Performed feature engineering to convert event-level data into session-level features.
- Used visualisations to analyse shopping patterns, purchase drop-offs and abandonment rates across product categories and brands.
- Built and compared three machine learning models: Logistic Regression, Decision Tree and Random Forest.
- Evaluated model performance using ROC-AUC, precision, recall and confusion matrices.
- Identified Random Forest as the best-balanced model for detecting high-risk shopping sessions.

Outcome:Provided data-driven recommendations to help e-commerce businesses reduce cart abandonment and improve purchase conversions.
